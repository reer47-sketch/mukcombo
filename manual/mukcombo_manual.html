01 먹콤보란?

먹콤보(MukCombo)는 "오늘 뭐 먹지?" 고민을 해결해주는 음식점 검색 & 먹방 기록 앱입니다. AI 추천, 카테고리 조합 검색, 메뉴명 검색으로 근처 음식점을 빠르게 찾고, 친구들과 먹은 기록을 피드에 남길 수 있습니다.

주요 기능 설명
🤖 AI 추천 인원수·시간대·입맛을 입력하면 AI가 최적의 음식점 3곳 추천
🔍 먹검색 먹고 싶은 메뉴명이나 카테고리 조합으로 음식점 검색
📸 피드 오늘 뭐 먹었는지 사진·메뉴·리뷰 기록 & 공유
🏪 점주 관리 내 가게 등록, 메뉴·가격·옵션 관리
02 시작하기

닉네임 설정 (로그인 없이 사용)

앱을 처음 열면 닉네임 입력 팝업이 나타납니다. 닉네임을 입력하면 로그인 없이도 리뷰 작성과 댓글을 이용할 수 있습니다.

닉네임은 기기에 저장되며, 언제든지 변경할 수 있습니다.

로그인 (선택사항)

계정을 만들면 다양한 기기에서 동일한 닉네임으로 이용할 수 있습니다.

방법 설명
Google 로그인 Google 계정으로 빠르게 로그인
이메일/비밀번호 이메일로 회원가입 후 로그인

탭 구성

화면 상단의 탭으로 기능을 이동합니다.

탭 기능
먹검색 AI 추천, 카테고리·메뉴명으로 음식점 검색
피드 다른 사람들의 리뷰 보기 & 내 리뷰 작성
관리 점주 로그인 및 가게 등록·편집
03 피드 — 리뷰 보기 & 작성

피드 보기

피드 탭에서 사람들이 남긴 먹방 기록을 스크롤하며 볼 수 있습니다.

  • 사진, 먹은 메뉴 조합, 리뷰 텍스트 확인
  • 댓글 보기: 리뷰 하단 댓글 수 버튼 클릭 → 목록 펼침
  • 댓글 작성: 입력란에 텍스트 입력 후 전송

리뷰 작성하기

피드 화면에서 "오늘 뭐 먹었어?" 버튼을 누르면 작성 폼이 열립니다.

1
음식점 선택
검색창에 가게명을 입력하거나 목록에서 가게를 선택합니다.
2
메뉴 선택
가게를 선택하면 메뉴 목록이 나타납니다.

메인 메뉴: 먹은 주 메뉴를 클릭 (여러 개 선택 가능).
메뉴에 옵션(사이즈, 국물 농도 등)이 있으면 선택지가 나타납니다.

사이드 메뉴: 곁들인 메뉴를 추가합니다 (선택사항).

메뉴를 선택하면 상단에 자동 문구가 생성됩니다.
3
리뷰 작성
사진 업로드(선택사항)와 리뷰 텍스트를 입력합니다.
4
공유
공유 버튼을 누르면 피드에 등록됩니다.
자동 생성 문구 예시
메뉴를 선택하면 자동으로 문구가 만들어집니다.
예: "고르다에서 돈코츠라멘 + 군만두 먹었어요!"
04 먹검색 — 음식점 찾기

먹검색 탭에서는 두 가지 방법으로 음식점을 찾을 수 있습니다.

방법 1 — AI 추천 받기

🤖 AI 추천 버튼을 누르면 챗봇이 세 가지 질문을 통해 최적의 음식점을 추천해줍니다.

단계 질문 선택지
1단계 몇 명이서 드세요? 혼자 / 2명 / 3~4명 / 5명+
2단계 언제 드세요? 점심 / 저녁 / 야식 / 상관없어요
3단계 어떤 음식이 당기세요? 카테고리 선택 또는 "아무거나"

추천 결과 카드

조건에 맞는 음식점 최대 3곳이 카드 형태로 표시됩니다.

  • 가게 이모지, 이름, ❤️ 좋아요 수
  • 📍 주소
  • 해당 카테고리의 메뉴 & 가격
  • 최근 리뷰 한 줄

카드를 클릭하면 전체 메뉴 상세 보기 모달이 열립니다.

방법 2-A — 메뉴명으로 검색

검색창에 먹고 싶은 메뉴명을 2글자 이상 입력합니다.

예시: 라멘  /  스테이크  /  파스타  /  돈코츠

잠시 후 해당 메뉴를 파는 음식점 목록이 나타납니다. 일치하는 메뉴명은 강조 표시됩니다.

방법 2-B — 카테고리 조합으로 검색

여러 음식 카테고리를 조합해 두 가지 이상을 한 곳에서 먹을 수 있는 음식점을 찾습니다.

1
카테고리 버튼을 클릭해 선택합니다 (여러 개 선택 가능).
2
선택한 카테고리가 라멘 + 맥주 형태로 표시됩니다.
3
"식당 찾기" 버튼을 눌러 검색합니다.
4
초기화하려면 "✕ 초기화" 버튼을 누릅니다.
카테고리는 일식, 중식, 한식, 이탈리아, 미국/서양 등 대분류별로 그룹화되어 있습니다.

음식점 상세 보기

검색 결과 카드를 클릭하면 상세 모달이 열립니다.

항목 내용
가게 정보 이름, 이모지, 주소, ❤️ 좋아요 수
지도 보기 링크 클릭 시 지도 앱 연결
메뉴 목록 섹션별로 메뉴명, 영문명, 가격 표시
05 점주 — 가게 등록 & 관리

로그인 및 권한

관리 탭을 클릭한 뒤 로그인합니다.

⚠️ 점주 권한은 관리자가 부여합니다. 로그인 후 점주 화면이 보이지 않는다면 운영팀에 문의해 주세요.

가게 등록하기

관리 탭 → + 새 가게 등록 버튼을 클릭합니다.

① 기본 정보 입력

항목 설명 예시
이모지 가게 대표 이모지 (기본값: 🍜) 🍣 🍔 🍕
가게명 (한글) 한국어 가게 이름 고르다
English Name 영문 가게 이름 Gorda
주소 한국어 주소 경기 평택시 …
Address (EN) 영문 주소 2F, 12 Pyeongtaek…
지도 URL 네이버·카카오맵 단축 링크 https://naver.me/…

② 메뉴 구성 — 섹션 추가

메뉴는 섹션 단위로 묶어 구성합니다. 섹션이란 점주가 직접 이름 붙이는 메뉴 그룹입니다.

섹션 예시: 라멘류 사이드 주류 디저트
1
+ 섹션 추가 버튼 클릭
2
섹션명 입력 (예: 라멘류)
3
섹션 내 + 메뉴 추가 버튼으로 메뉴 항목을 추가

③ 메뉴 항목 입력

항목 설명
메뉴명 한국어 메뉴 이름
Menu (EN) 영문 메뉴 이름
가격 숫자만 입력 (원 단위)
카테고리 검색 노출용 음식 카테고리 연결 (아래 참조)

④ 카테고리 연결 (검색 노출에 중요)

카테고리를 연결해야 먹검색에서 해당 메뉴가 검색됩니다.

방법 설명
자동 추천 수락 메뉴명 입력 시 💡 라멘 자동추천 표시 → ✓ 수락 클릭
직접 선택 직접 선택 또는 + 카테고리 선택 클릭 → 그룹 필터 또는 검색으로 선택
변경 선택된 카테고리 오른쪽 ✕ 버튼으로 해제 후 재선택

⑤ 순서 변경 & 삭제

  • ▲ ▼ 버튼: 섹션 또는 메뉴의 위아래 순서를 변경합니다.
  • ✕ 버튼: 섹션 또는 메뉴를 삭제합니다 (최소 1개는 유지됩니다).

옵션 설정 (선택사항)

메뉴마다 선택 옵션(사이즈, 토핑 등)을 추가할 수 있습니다.

1
메뉴 하단 ⚙ 옵션 추가 버튼 클릭
2
옵션명 입력 (예: 국물 농도) + 영문명 입력
3
선택지 텍스트 입력 (예: 기본 / 진하게) + 추가 가격 설정 (없으면 0)
4
+ 선택지 버튼으로 선택지를 더 추가할 수 있습니다.

가게 저장

모든 입력 후 하단 가게 등록 완료 🎉 버튼을 클릭합니다.

가게 편집하기

등록된 가게 목록에서 ✏️ 메뉴 편집 버튼을 클릭합니다.

편집 화면에서 섹션명, 메뉴, 가격, 옵션을 모두 수정할 수 있습니다.

버튼 기능
저장 변경사항 저장. 완료 시 저장됨 ✓ 표시
미리보기 실제 고객에게 보이는 형태로 메뉴 확인
← 목록 편집 완료 후 가게 목록으로 돌아가기
저장 버튼을 누른 뒤 "저장됨 ✓" 표시가 나타나면 저장이 완료된 것입니다. 확인 후 ← 목록 버튼으로 나가세요.
